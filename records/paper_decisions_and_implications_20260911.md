# 논문용 결정 근거와 함의 — 내부 전극 탐색에서 조건부 외부 검증까지

작성2026-09-11. **소급 연구 근거집의 보충문**이며 최종 투고 원고나 임상 결론이 아니다.
기존 [종합 근거집](paper_synthesis_20260910.md)의 방법·수치·원자료 연결을 유지한다.
아래에서 관측, 설계 선택, 해석과 미검증 가설을 구분한다. 외부평가 보류는 내부
전수탐색 실패를 뜻하지 않으며, 내부 탐색 완료도 외부 검증 완료를 뜻하지 않는다.

## 1. 연구 질문이 구체화된 이유

처음 질문은1–4리드793조합 가운데 어떤 조합이 좋은가였다. 그러나 착용 부담을 줄이는
설계에서는 입력 채널 수보다 실제 피부 접촉점 수가 직접적인 비용이다. 세 사지 접촉점으로
여러 사지유도를 만들 수 있으므로, 입력을4개로 제한하면 같은 접촉 비용으로 가능한
5개 이상의 입력 구성을 누락한다. 그래서 비공집합4095개 전체로 확장했다.

이 결정의 근거는 측정 기하와 기존 탐색 범위의 불일치다. “많이 돌리면 논문이 된다”는
이유가 아니며, 관련 연구가 없다는 전제도 아니다. 문헌은
[관련 연구 검토](paper_related_work_20260909.md)에 남아 있다. 현재 방어 가능한 기여는
이 동결 모델·데이터·입력 규칙에서의 전수 비교와, 물리적 비용·약한 질환군·불확실성을
함께 추적하는 실험 자료다. 최초성이나 모든 모델에 대한 보편 최적성은 검증하지 않았다.

## 3. 현 결과가 실제로 시사하는 것

내부 후보 표에서 가장 적은 측정 접촉점을 사용하는II는2접촉이며, 선택한 여덟 후보의
반복 평균 Macro-F1은 대략0.689–0.703 범위다. 이 좁은 범위만으로 동등성을 입증할 수
없다.12리드 대비 paired 차이 구간이0을 포함한다는 사실 역시 동등성 검정의 통과가
아니다. 최소 전극 설계의 합격 기준은 실제 위험·목표 질환·허용 성능 손실을 정하고
별도 검증해야 한다. 현재 자료에서 점수가 가까운 후보들은 그 검증을 위한 후보군이다.

V1+V2가 seed42에서 네 질환의 민감도 바닥0.50을 넘은 결과는 반복 평가에서 그대로
유지되지 않았다. 이소성의10seed 평균은0.470732, 최솟값은0.426829였다. 따라서
“최소 전극으로 네 질환을 안정적으로 모두 관측한다”는 결론은 현재 수치가 지지하지
않는다. 이 음성 결과는 연구의 실패로 삭제할 내용이 아니라, 평균 성능과 취약 질환의
신뢰성이 서로 다른 선택 기준이라는 직접 근거다.

Macro-F1은 각 클래스의 정밀도와 재현율을 결합한 F1을 동일 가중 평균한 값이다.
현재 내부 Macro-F1은 정상을 포함한5개 클래스의 평균이며, 전체 정답 비율인 정확도와
다르다. 민감도는 실제 해당 질환으로 라벨된 기록 중 잡아낸 비율이다. ROC에서 고른
Sens@95Sp와 argmax confusion의 재현율은 결정 규칙이 달라 같은 값일 필요가 없다.
주장에는 지표 이름뿐 아니라 정답 단위·클래스 집합·운영점 선택 자료를 함께 적어야 한다.

## 4. 오늘 추가된 재현 근거와 그 한계

기존936 test의 ID 순서를 그대로 사용하고 원 `.hea/.mat`에서 검증된 `load_signal`
경로로 재생성했다. 신호는(936,12,5000) float32이고, 재생성 signals·5-class labels·
binary labels 파일의 SHA256이 원 파일과 일치했다. 최대 신호 차이는0, 실패·스킵0이다.
원 ID 파일은 순서를 정의하는 입력으로 복사했으므로 “독립적으로 split을 복원했다”는
증거로 세지 않는다. 상세 기록은
`results/external_readiness_final_20260911/cpsc_test_control.json`과 원자료별 해시 대장이다.

이 대조는 원 전처리 경로가 현재 환경에서 해당 test를 정확히 재현함을 보여준다.
아직 원본 파형이 없는 validation933을 역사적 원 배열과 직접 대조한 것은 아니다.
검증 배열 생성, 임계값 산출·커밋, 외부 추론은 여전히 미실행이다. 재현 대조 통과는
학습 누수 부재나 임상 정답 정확성을 증명하지 않는다.

확대 PTB-XL 감사의3832→15768,11838→11839 두 쌍은12유도 모두에서 샘플 차이가
있고 최대 디지털 차이는 각각62와70이었다. 각 유도 상관은 높지만 정확히 동일하지
않았다. 획득 실패가 해결된 뒤 실제 로컬 파형을 대조한 관측이며 차이의 생성 원인은
미확인이다. 원인이 필터링·편집·다른 기록 중 무엇인지 이 상관만으로 판정하지 않는다.
F3 제외에 직접 사용한142→13803,11810→15741은 정확히 일치했다. 코호트 해시도
유지됐다. 이 두 사실을 함께 보고해야 전체 필터가 무효라거나 전체 동일성이 입증됐다는
양방향 과장을 피할 수 있다.

## 5. 선택 편향·불확실성·하드웨어 설명의 경계

4095개 조합을 같은 test에서 비교한 뒤 후보를 고른 단계는 탐색이다. 같은 자료에서의
bootstrap이나 seed 반복은 후보 선택의 낙관 편향을 제거하는 독립 검증이 아니다.
seed 반복은 특징 마스크 변동, record bootstrap은 관측 표본 변동을 대상으로 한다.
환자 ID가 없었던 내부 분석의 기록 단위 구간은 환자 의존성을 완전히 반영하지 못한다.
외부 patient-cluster bootstrap도 데이터베이스 ID의 정확성을 별도로 입증하지는 않는다.

홈PC의 제한된 계산 자원이 과거 탐색 범위를 제한했을 가능성과, 그 제한이 낮은
질환별 점수의 원인이라는 주장은 구별한다. 새 GPU로 더 많은 조합을 계산한 것은 탐색
범위를 넓혔지만 모델 표현, 라벨 오류, 표본 부족 또는 실제 측정 신호 손실의 원인을
분리하는 실험은 아니다. 하드웨어 자원 증가가 정확도를 개선했다고 쓰려면 같은 모델·
자료에서 수치정밀도·실행 조건을 대조하거나 학습 예산을 통제한 별도 실험이 필요하다.

5c metadata replay의1012/1682 (약60.17%) 중첩은 중요한 노출 위험 지표지만 현재
가중치의 학습 로그가 아니다. 역사적 학습 건수와 재구성 건수의2건 차이 및5d
warm-start 미확인을 함께 명시한다. 그 위험을 숨기지 않는 것과 실제 오염률을 확정하는
것은 다르다. 외부 결과를 얻더라도 현재 계보 조건에서는 조건부 외부 검증으로 제한한다.

## 6. 원고에 사용할 수 있는 논의 문단

“본 연구는 동결 ECG 분류기에서 입력 부분집합과 표준 측정 접촉점 비용 사이의 관계를
전수적으로 비교하였다. 일부 저접촉 구성은12리드 기준과 가까운 집계 성능을 보였으나,
질환별 민감도와 확률적 특징 마스크에 대한 안정성은 균일하지 않았다. 특히 단일 실행의
포괄적 커버리지가 반복 평가에서 유지되지 않아, 평균 지표만으로 최종 센서 구성을
결정하는 접근의 한계를 확인하였다.”

“재현성 감사에서는 원 test 파형과 라벨의 바이트 단위 재구성을 확인했으며, 외부 자료의
버전 간 삭제·유지 관계를 확대 조사하면서 정확한 파형 동일성에 대한 기존 표현을
정정하였다. 이러한 검사는 결과의 독립성이나 임상 유효성을 대신하지 않는다. 본 자료는
후속 검증의 후보와 실패 가능성을 명시하는 탐색 근거이며, 임상적으로 확정된 최소
전극 수 또는 장기 착용 응급 경보의 성능을 제시하지 않는다.”

이 문단은 사후 해석이다. 실험 전 정한 내용은 원 프로토콜, 외부 결과 전 명세 보완은
2026-09-11 개정문, 관측 수치는 CSV/JSON으로 각각 인용해야 한다. 후속 결과가 없는데
예상 결과를 Results 절에 옮겨 쓰지 않는다.
